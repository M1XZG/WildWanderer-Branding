# Blog branding — Wild & Wandering (blog.wildwanderer-vr.com)

Assets and styling for the Ghost blog "Wild & Wandering".

## Contents
- `code-injection.html` — full Ghost Code injection (Settings -> Code injection -> Site header). Casper theme, dark neon, doras background image, pink/purple cards, large logo, transparent footer (logo only). Hides subscribe/signup/comments UI.
- `images/ww-logo-trim.png` — trimmed transparent logo (used for header + footer).
- `images/ww-social-card.png` — 1200x630 social/OG card (publication cover) for Discord/X link previews.
- `images/ww-social-square.png` — 1024x1024 square social card.
- `images/ww-icon.png` — 512x512 publication icon / favicon (logo on solid dark).

## Notes
- Background image is the same as wildwanderer-vr.com (doras CDN).
- Body font: Poppins.
- Palette: pink #FFA5EE, purple #800080, off-white #E6E6E6, near-black #0F0F0F.
